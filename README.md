# Vanshdeep Sharma — Developer Portfolio Website

Official personal portfolio website for **Vanshdeep Sharma** (Final-Year B.Tech in Computer Science Engineering — Artificial Intelligence & Data Science at CGC Landran, Punjab, India).

## What's Inside This Archive

1. **`vanshdeep_sharma_portfolio.html` & `standalone/index.html` (Zero-Build Standalone Website)**
   - Complete, self-contained single-file production bundle containing all sections, interactive project filtering, case-study modals, 8-track career matrix, inline Customize Mode, Dark/Light theme switcher, and interactive Resume Studio.
   - **How to run**: Double-click `vanshdeep_sharma_portfolio.html` in any browser, or upload `standalone/index.html` directly to **GitHub Pages**, **Netlify Drop**, or **Vercel** with zero build configuration required.

2. **Modular React + Vite + Tailwind CSS Project (`src/`, `package.json`, `vite.config.js`)**
   - Cleanly structured React 18 + Tailwind CSS + Lucide React + Framer Motion codebase.
   - All personal information, 8-Track skill matrices, GitHub projects, and certifications are stored in **`src/data/resumeData.js`** so you can easily add new projects or update skills in one place.
   - **How to run locally**:
     ```bash
     npm install
     npm run dev
     ```
   - **How to build for production**:
     ```bash
     npm run build
     ```
